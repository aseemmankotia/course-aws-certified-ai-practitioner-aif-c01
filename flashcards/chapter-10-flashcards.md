## Chapter 10: Full Practice Exam + Test-Taking Strategy (65 Questions) — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | AIF-C01 exam format: total questions, scored questions, time limit, passing score? | 65 total questions (50 scored, 15 unscored pretest items), 90 minutes, passing score 700/1000 (scaled). Exam tip: You won't know which 15 are unscored - treat all equally. Time budget: 1.38 min/question average, aim for 1.5 min max. |
| 2 | Question type distribution on AIF-C01 exam? | 40% scenario-based (situation → choose best solution), 30% service selection (which AWS service), 20% configuration (settings/values), 10% conceptual (definitions/comparisons). Exam tip: Practice scenarios most - they're worth 26 of 65 questions. |
| 3 | When does RAG vs fine-tuning make sense? (keyword test) | RAG: 'frequently changing data', 'current information', 'query external sources', 'dynamic content'. Fine-tuning: 'change model behavior/style/tone', 'domain-specific responses', 'static knowledge'. Exam trap: RAG for factual updates, fine-tuning for behavior changes. |
| 4 | Amazon Bedrock vs SageMaker - when to use which? | Bedrock: Pre-trained foundation models via API, no infrastructure, quick start, prompt engineering, RAG. SageMaker: Custom model training, full ML pipeline control, bring your own algorithm, fine-grained tuning. Exam keyword: 'no ML expertise' or 'quick deployment' = Bedrock. |
| 5 | Amazon Comprehend vs Textract - key difference exam tests? | Comprehend: NLP on TEXT (sentiment, entities, PII detection, language detection). Textract: Extract text from IMAGES/PDFs (OCR), forms, tables. Exam trap: If question mentions 'PDF' or 'scanned docs' → Textract first, then Comprehend for analysis. Order matters. |
| 6 | Provisioned throughput break-even: when is it cost-effective? | Cost-effective when: continuous 24/7 high-volume inference, predictable load, utilization >70%. NOT cost-effective: batch processing, irregular traffic, low volume. Exam tip: Calculate $/hour × hours used vs on-demand $/request × requests. Consider UTILIZATION not just unit price. |
| 7 | Amazon Textract: Synchronous vs Asynchronous API - when to use? | Sync: Real-time (<1 sec), single document, immediate response needed. Async: Batch processing, multi-page PDFs, can wait minutes, cheaper ($1.50 vs $1.80/1000 pages for AnalyzeDocument). Exam keyword: 'cost-optimized' + no real-time requirement = async. |
| 8 | Test-taking strategy: elimination technique for AIF-C01? | Step 1: Cross out 2 obviously wrong answers (usually too expensive, wrong service, or doesn't meet requirement). Step 2: Between remaining 2, look for keywords: 'cost-optimized', 'highly available', 'scalable'. Step 3: Choose answer matching most keywords. Trust first instinct unless clear error. |
| 9 | Time management strategy for 65 questions in 90 minutes? | Budget: 1.5 min/question (65 × 1.5 = 97.5 min, allows for review). First pass: spend max 2 min on hard questions, flag 15-20 for review. After completing all: 15 minutes remaining for flagged review. Exam tip: Don't spend 5+ min on any single question - flag and move on. |
| 10 | Common AIF-C01 keyword map for service selection? | 'Frequently changing data' → RAG. 'Change model style/tone' → fine-tuning. 'Highly available' → Multi-AZ/region. 'Cost-optimized' → on-demand pricing, right-sizing, async APIs. 'Real-time' → sync APIs, provisioned throughput. 'Secure' → VPC, encryption, IAM policies. Memorize these keyword→solution pairs. |
| 11 | Amazon Transcribe: Custom vocabulary vs Custom language model (CLM)? | Custom vocabulary: List of specific words/phrases (brand names, acronyms), improves spelling. CLM: Trained on domain text corpus, understands context and relationships, better for jargon and phrases. Exam: 'Industry terminology' or 'context-aware' = CLM. 'Brand name spelling' = custom vocabulary. |
| 12 | Imbalanced dataset problem: what's the standard ML fix exam expects? | Class weighting (assign higher loss to minority class) or focal loss (focus on hard examples). NOT: more epochs (doesn't fix optimization), undersampling (loses data), ignoring accuracy metric. Exam tip: 99% accuracy but predicting all one class = use class weighting/focal loss, not more training time. |
