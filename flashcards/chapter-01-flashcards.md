## Chapter 1: Domain 1: AI/ML Fundamentals & AWS Service Portfolio — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | What's the key difference between supervised and unsupervised learning for the exam? | Supervised = labeled training data (you know correct answers). Unsupervised = unlabeled data (algorithm finds patterns). Exam tip: If question mentions 'historical data with outcomes' or 'labeled examples' → supervised. If it says 'no predefined categories' or 'discover patterns' → unsupervised. |
| 2 | SageMaker training job lifecycle—what are the 4 main phases the exam tests? | 1) Data preparation (S3 input), 2) Training (algorithm + hyperparameters), 3) Model artifacts saved (S3 output), 4) Deployment (endpoint or batch). Exam tip: Questions often ask 'what happens after training completes' → model artifacts save to S3, NOT automatic deployment. |
| 3 | When does the exam want you to choose Comprehend vs Rekognition? | Comprehend = TEXT analysis (sentiment, entities, PII, language detection). Rekognition = IMAGE/VIDEO analysis (faces, objects, scenes, content moderation). Exam trick: If question shows image of text → use Textract first (extract), then Comprehend (analyze). |
| 4 | What's the difference between classification and regression in supervised learning? | Classification = predict discrete categories (spam/not spam, cat/dog/bird). Regression = predict continuous values (house price, temperature). Exam tip: Look for question context—'predict which category' → classification, 'predict amount/value' → regression. |
| 5 | Amazon Transcribe custom vocabulary—what's the maximum number of words/phrases? | 50,000 words/phrases per custom vocabulary. Exam note: Questions often give scenario with technical jargon or product names → custom vocabulary is the solution. Standard Transcribe works for general speech, custom vocabulary for domain-specific terms. |
| 6 | What are the 3 main unsupervised learning types the exam tests? | 1) Clustering (group similar data—K-means), 2) Anomaly detection (find outliers—Random Cut Forest), 3) Dimensionality reduction (reduce features—PCA). Exam tip: 'Customer segmentation' = clustering, 'fraud detection' = anomaly detection. |
| 7 | SageMaker endpoint—what does automatic scaling scale based on? | Invocations per instance (requests/minute per instance). Default target: 1000 invocations per instance. Exam tip: Questions about variable traffic → enable automatic scaling. Fixed traffic → single instance is cheaper. Scales OUT (more instances), not UP (bigger instances). |
| 8 | Amazon Comprehend PII detection—what entity types does it detect? | Built-in: SSN, credit card, bank account, phone, email, address, name, age, IP address, AWS keys, passport, driver's license. Exam tip: If question asks 'redact sensitive data from documents' → Comprehend PII detection. Don't overthink with regex or custom models. |
| 9 | What's data drift and why does the exam test it? | Data drift = when real-world data distribution changes from training data distribution. Causes model accuracy to drop over time. Exam scenario: 'Model was 90% accurate, now 65% after 6 months' → data drift, needs retraining. Solution: Monitor with SageMaker Model Monitor. |
| 10 | Amazon Rekognition custom labels minimum training images? | Minimum 10 images per label, but AWS recommends 50+ per label for good accuracy. Exam tip: If scenario mentions 'only 5 sample images' → not enough for custom labels. Standard Rekognition labels (1000+ built-in) don't need training. |
| 11 | ML lifecycle—what comes AFTER deployment that the exam tests? | Monitoring (track accuracy, latency, data drift) → Retraining (when accuracy drops). Exam trick: Many students forget monitoring. Questions ask 'what's the final step' → deployment is NOT final, monitoring is part of lifecycle. |
| 12 | Transcribe speaker identification (diarization)—what's the maximum number of speakers? | Maximum 10 speakers per audio file. Exam note: Questions about call center recordings with 'multiple agents' → use speaker identification. Medical transcription use case → Transcribe Medical has specialized vocabulary but same speaker limit. |
