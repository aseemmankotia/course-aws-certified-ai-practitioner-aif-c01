## Chapter 3: Domain 2: Generative AI Fundamentals & Transformer Architecture — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | How many tokens does 'Hello world' typically produce? | 2 tokens. Each word is typically one token. Exam tip: Tokenization splits text into smallest meaningful units (words, subwords, or characters). Count matters because more tokens = higher API costs and longer processing time. |
| 2 | What is the embedding dimension size for GPT-3.5? | 1536 dimensions. Each token is converted to a 1536-dimensional numerical vector. Exam tip: Embeddings are the numerical representation that models process - larger dimensions can capture more semantic nuance but require more compute. |
| 3 | What is the computational complexity of transformer self-attention? | O(n²) where n = sequence length. Must compute attention between all token pairs. Exam tip: Doubling sequence length quadruples compute/memory. For 1000 tokens = 1 million pair comparisons. |
| 4 | Foundation model vs fine-tuned model: when to use which? | Foundation model: zero-shot tasks, limited task-specific data, general use. Fine-tuned model: specialized domain (medical, legal), have labeled data (10k+ examples), need higher accuracy. Exam tip: Fine-tuning requires less data/compute than pre-training from scratch. |
| 5 | Why did transformers replace RNNs as the dominant architecture? | Two reasons: (1) Parallelization - transformers process all tokens simultaneously vs RNN's sequential processing = faster training. (2) Long-range dependencies - self-attention directly connects distant tokens vs RNN's gradual information flow. Exam tip: Despite O(n²) complexity, parallelization wins. |
| 6 | Token vs Embedding vs Vector: what's the difference? | Token = discrete text unit ('Hello'). Embedding = numerical vector representation of a token (e.g., [0.23, -0.45, ...]). Vector = generic term for array of numbers. Exam tip: Token→Embedding is the first processing step. Embedding and vector are often used interchangeably. |
| 7 | What are the stages of the GenAI lifecycle in order? | 1) Pre-training (on billions of tokens, creates foundation model), 2) Fine-tuning (on task-specific data), 3) Alignment/RLHF (human feedback for safety), 4) Deployment. Exam tip: Pre-training is most expensive (thousands of GPUs), fine-tuning is accessible (few GPUs). |
| 8 | What is self-attention in transformers? | Mechanism that computes relevance between all token pairs in parallel. For each token, calculates attention scores to every other token to determine which tokens to focus on. Exam tip: 'Self' means tokens attend to other tokens in the same sequence (not external data). |
| 9 | What makes a model a 'foundation model'? | Three characteristics: (1) Pre-trained on massive data (billions of parameters), (2) Zero-shot capable (can perform tasks without task-specific training), (3) General-purpose (not specialized). Exam tip: Examples include GPT-4, Claude, Titan - NOT task-specific fine-tuned models. |
| 10 | If sequence length doubles in a transformer, how does memory usage change? | Quadruples (4x). Because self-attention is O(n²): 100 tokens = 10k pairs, 200 tokens = 40k pairs (4x). Exam tip: This is why context windows are limited - 100k tokens would need 10 billion pair computations. |
| 11 | What is RLHF and where does it fit in the GenAI lifecycle? | Reinforcement Learning from Human Feedback - trains models to be helpful, harmless, honest using human preferences. Comes AFTER fine-tuning, BEFORE deployment (alignment stage). Exam tip: RLHF addresses safety/harmful outputs, not accuracy on specific tasks. |
| 12 | Transformer encoder-decoder: what does each component do? | Encoder: processes input sequence using self-attention (understands context). Decoder: generates output sequence using self-attention + cross-attention to encoder (produces response). Exam tip: Some models are encoder-only (BERT), decoder-only (GPT), or both (T5). |
