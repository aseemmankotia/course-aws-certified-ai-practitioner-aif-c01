## Chapter 9: Domain 5: Security, Compliance & Governance for AI — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | What is the exact IAM permission required to invoke a Bedrock foundation model? | bedrock:InvokeModel Exam tip: Must specify the exact permission name. Also need resource ARN restriction for least privilege: arn:aws:bedrock:region::foundation-model/model-id |
| 2 | Cost per KMS customer-managed key (CMK) per month? | $1/month per CMK Exam tip: Additional $0.03 per 10,000 encryption/decryption requests. Required for customer-controlled encryption at rest (S3, EBS, SageMaker) |
| 3 | What TLS version is automatically enforced for Bedrock and SageMaker API calls? | TLS 1.2 or higher (automatically enforced) Exam tip: Data in transit encryption is automatic for AWS AI services. No configuration needed. Common exam scenario: 'How to encrypt data in transit?' → Already done automatically |
| 4 | Amazon Macie cost for scanning S3 data? | $1 per GB scanned Exam tip: Macie = ML-powered PII/sensitive data discovery in S3. Use when requirement is 'find PII' or 'scan for sensitive data'. Different from GuardDuty (threat detection) |
| 5 | Exact VPC endpoint service name for Bedrock Runtime API? | com.amazonaws.region.bedrock-runtime Exam tip: Use when requirement is 'no internet access' or 'private connectivity'. Replace 'region' with actual region (e.g., us-east-1). Note: bedrock-runtime, not just bedrock |
| 6 | CloudTrail S3 storage cost per GB per month? | $0.025/GB/month (S3 Standard) Exam tip: Use CloudTrail for logging Bedrock API calls. Enable data events to capture InvokeModel calls. Lifecycle to Glacier Deep Archive ($0.00099/GB/month) for long-term retention |
| 7 | IAM permission to list available Bedrock foundation models? | bedrock:ListFoundationModels Exam tip: Read-only operation, often paired with bedrock:GetFoundationModel. Different from bedrock:InvokeModel which is the write operation for using models |
| 8 | When to use AWS Audit Manager vs AWS Config? | Audit Manager: Automated compliance evidence collection for frameworks (SOC 2, PCI-DSS), generates audit reports Config: Continuous compliance assessment, evaluates resource configurations Exam tip: Compliance audit preparation → Audit Manager. Continuous monitoring → Config |
| 9 | Customer vs AWS responsibility for Bedrock security? | AWS: Infrastructure security, model availability, API endpoint security Customer: IAM policies, data encryption, KMS keys, VPC configuration Exam tip: Customer = data and access control. AWS = infrastructure and service operation. Always choose customer responsibility for IAM/encryption in exam |
| 10 | What does enabling SageMaker network isolation do? | Prevents training/inference containers from making outbound network calls (no internet access) Exam tip: Different from VPC endpoints. Network isolation = block outbound. VPC endpoint = private inbound path. Use together for maximum security |
| 11 | Pre-built compliance frameworks available in AWS Audit Manager? | SOC 2, PCI-DSS, HIPAA, GDPR, ISO 27001, and others Exam tip: Audit Manager automates evidence collection for these frameworks. When exam asks about 'demonstrating compliance' or 'audit preparation' → Audit Manager |
| 12 | What encryption is required for SageMaker notebook instances to meet compliance? | EBS volume encryption with KMS (customer-managed key recommended) Exam tip: Notebooks store code and data on EBS. Encryption at rest = KMS for volume. Encryption in transit = TLS (automatic). $1/month per CMK |
